# PENGUINS 데이터 분석 실습

펭귄(penguins) 데이터로 **데이터 읽기 → 특성 분석 → 결측치 처리 → 이상치 처리 → 정규화**를 차례로 익히는 인터랙티브 학습지입니다. 학생은 코드의 빈칸을 채우고 **▶ 실행**을 눌러 결과를 확인한 뒤, 연습문제로 결과를 해석합니다.

[python-iris](https://github.com/onezerozerocom/python-iris)와 같은 형식으로, 데이터와 활동 내용을 펭귄 데이터에 맞게 바꾼 버전입니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 페이지 뼈대 (제목, 흐름 스트립, 단계 목록, 본문 영역) |
| `style.css` | 디자인 (색상 토큰, 라이트/다크 모드, 반응형 레이아웃) |
| `app.js` | 데이터, 계산, 활동·연습문제 내용, 화면 그리기, 이벤트 처리 |
| `penguins.csv` | 실습 데이터 원본 (`app.js`에도 같은 내용이 들어 있음) |

별도 설치나 빌드는 필요 없습니다. 외부에서 불러오는 것은 Google Fonts 글꼴뿐입니다.

## 실행 방법

- `index.html`을 브라우저로 열면 됩니다. 더블클릭으로 열어도(`file://`) 동작합니다.
- 웹에 올릴 때는 파일들을 같은 폴더에 두면 됩니다. GitHub Pages 등 정적 호스팅이면 충분합니다.

## 학습 구성

| 단계 | 내용 | 활동 | 연습문제 |
| --- | --- | --- | --- |
| 먼저 알아보기 | 펭귄을 관찰해 볼까요? → penguins.csv 전체 내용(결측치 표시 전환) → 한눈에 → CSV 속성 | – | – |
| 1. 데이터 읽기 | `pd.read_csv()`, `head()` | 01 | – |
| 2. 특성 분석 | `info()`, `describe()` | 02, 03 | 3문항 |
| 3. 결측치 | `isnull().sum()`, `mean(numeric_only=True)`, `fillna()` | 04, 05, 06 | 3문항 |
| 4. 이상치 | 열별 상자그림(`subplot(1, 4, n)`), `np.percentile(axis=0)`로 IQR 계산, `any(axis=1)`, `drop()` | 07, 08, 09 | 3문항 |
| 5. 정규화 | `MinMaxScaler`, 정규화 전후 상자그림 | 10, 11 | 3문항 |

## iris 버전과 다른 점

- **결측치**: iris는 한 열(PetalLength)에만 결측치가 있었지만, 펭귄은 수치형 네 열 모두에 있습니다. 그래서 `penguins.mean(numeric_only=True)`로 열별 평균을 구해 `fillna(mean)`으로 한 번에 채웁니다.
- **이상치**: iris는 SepalWidth 한 열만 검사했지만, 펭귄은 네 열 모두 검사하고 **하나라도** 이상치가 있는 행을 지웁니다 (`mask.any(axis=1)`).
- **상자그림**: 열마다 단위·크기가 크게 달라(mm와 g) 활동 07은 열마다 따로 그립니다. 활동 11의 정규화 전 그림에서는 body_mass_g 때문에 나머지 열이 납작하게 보여 정규화가 왜 필요한지 드러납니다.

## 이 데이터의 주요 결과값

- 결측치 9칸: bill_length_mm 2 (12, 73번), bill_depth_mm 2 (25, 95번), flipper_length_mm 2 (47, 140번), body_mass_g 3 (19, 52, 117번)
- 열별 평균: 44.966216, 17.402703, 202.344595, 4272.448980
- 결측치를 채운 뒤 이상치 6개 (각각 다른 행) → 제거 후 144행
  - bill_length_mm 115.4 (7번), 2.5 (129번) · bill_depth_mm 42.9 (88번) · flipper_length_mm 421.0 (61번) · body_mass_g 12500.0 (33번), 850.0 (104번)
  - body_mass_g: Q1 = 3600, Q3 = 4956.25, IQR = 1356.25, 상한 6990.625, 하한 1565.625

값은 pandas 3 / numpy로 직접 계산해 확인했습니다.

## 동작 방식: 파이썬을 실제로 실행하지 않습니다

데이터가 고정된 penguins.csv이므로 결과를 JavaScript로 미리 계산해 보여 줍니다. 학생이 쓴 답은 정해진 정답 목록과 비교하며, 띄어쓰기는 무시합니다.

## 수정하는 방법 (`app.js`)

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 활동의 코드, 빈칸 정답, 설명, 실행 결과 | `ACTS` 객체. 코드 줄의 `{0}`, `{1}`이 빈칸이고, `blanks[k].a`에 정답을 여러 개 넣을 수 있습니다. |
| 연습문제 | `QUIZ` 객체. `a`는 정답 번호(1부터), `e`는 해설입니다. |
| 단계 제목, 목표, 개념 설명 | `STEPS` 배열 |
| 색상, 글꼴, 간격 | `style.css` 맨 위 `:root`의 변수 |

진행 상황은 브라우저의 `localStorage`(`penguins-lab-v1` 키)에 저장됩니다.

데이터는 `app.js` 맨 위 `PENG_CSV`에 있고 통계량은 자동으로 계산됩니다. 연습문제의 숫자도 대부분 계산값을 쓰지만, 활동 03 문제의 2.5·115.4·39.1·49.4와 이상치 보기(115.4, 421.0, 6775.0, 850.0)는 직접 쓴 값이라 데이터를 바꾸면 함께 고쳐야 합니다.
